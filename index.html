Application de Référence Pédagogique

DzPédiatrie est une plateforme éducative et documentaire en pédiatrie. L'ensemble du contenu est strictement informatif et de référence — à vérifier selon les protocoles officiels par un professionnel de santé qualifié.

Contenu strictement éducatif et documentaire. DzPédiatrie ne constitue pas un avis médical professionnel et ne remplace pas la consultation d'un médecin ou d'un professionnel de santé qualifié. En cas d'urgence médicale réelle, contactez immédiatement les services d'urgence officiels.

1. Identification de l'Éditeur

Éditeur : DzPédiatrie — Plateforme éducative en pédiatrie, Algérie.

Type : Application mobile de référence documentaire et pédagogique en pédiatrie.

Objectif : Fournir un accès informatif et éducatif à des documents de référence en pédiatrie, destinée aux utilisateurs recherchant des ressources pédagogiques et documentées en pédiatrie.

DzPédiatrie est positionnée comme une ressource éducative et de référence. L'ensemble du contenu est documentaire et doit être vérifié selon les protocoles officiels.

2. Nature du Service

DzPédiatrie est une application de référence éducative et documentaire en pédiatrie, destinée à un usage strictement informatif.

Caractéristiques principales :

  • Base de données de référence : Accès à des informations documentées sur les médicaments, posologies, calendriers vaccinaux, et protocoles de référence en pédiatrie.
  • Outil de calcul pédagogique : Calculateur de doses à titre indicatif et éducatif uniquement — résultats à vérifier selon les protocoles officiels.
  • Références pédagogiques : Informations de référence générées par intelligence artificielle, à titre documentaire et éducatif.
  • Calendrier vaccinal de référence : Informations documentées sur le calendrier vaccinal algérien à usage éducatif.

Usage strictement éducatif :

  • L'application ne constitue pas un avis médical ou une consultation de quelque nature que ce soit.
  • Les informations ne remplacent pas le jugement clinique d'un professionnel de santé qualifié.
  • L'application ne diagnostique pas et ne prescrit pas de traitement.
  • Les résultats des calculateurs doivent être vérifiés selon les protocoles officiels avant toute utilisation réelle.

En cas d'urgence médicale réelle concernant un enfant, contactez immédiatement les services d'urgence officiels (15 ou 112 en Algérie).

3. Collecte de Données

Données collectées lors de l'inscription :

  • Nom d'utilisateur et mot de passe : Pour la création et gestion du compte utilisateur.
  • Profil utilisateur : Informations saisies par l'utilisateur (ex : étudiant en médecine, professionnel de santé, pharmacien) pour positionner le contenu comme référence documentaire.
  • Nom de la structure : Optionnel, pour référence personnelle.

Données pédagogiques (à usage éducatif uniquement) :

  • Données des patients fictionalisés : Création de fiches patients à usage strictement éducatif et de référence, ne constituant pas un dossier médical réel.
  • Âge et poids de l'enfant : Saisis dans le calculateur pédagogique pour générer des résultats de référence informatifs — résultats à vérifier selon les protocoles.
  • Antécédents médicaux sommaires : Champ optionnel à titre documentaire et de référence uniquement.

Données de navigation et de performance :

  • Logs de performance anonymisés pour améliorer l'expérience utilisateur de référence documentaire.
  • Données d'utilisation statistiques (sans identification personnelle) pour évaluer la pertinence du contenu éducatif.

DzPédiatrie ne constitue pas un système de gestion clinique. Toutes les fiches patients sont fictionalisées et à usage strictement éducatif.

4. Stockage Local

Base de données SQLite locale :

  • Contenu documentaire : Base de données locale contenant les informations de référence en pédiatrie (médicaments, posologies, formes pharmaceutiques, calendriers vaccinaux).
  • Données de référence : Informations sur les principes actifs, classes thérapeutiques, et marques algériennes courantes.
  • Données de vaccination : Contenu du calendrier vaccinal algérien avec règles de rattrapage.

Gestion des fiches patients fictionalisées :

  • Les fiches patients créées dans l'application sont stockées uniquement sur l'appareil de l'utilisateur (stockage local).
  • Aucune synchronisation des fiches patients avec un serveur cloud n'est effectuée.
  • Les fiches patients constituent des exemples éducatifs fictionalisés et ne constituent pas un dossier médical protégé.

Suppression des données locales :

  • La désinstallation de l'application supprime automatiquement l'ensemble des données locales.
  • Pour supprimer les données locales sans désinstallation, contactez l'éditeur via les canaux indiqués dans la section contact.

5. Services Cloud

Infrastructure Supabase :

  • Authentification : Service d'authentification Supabase pour la gestion des comptes utilisateurs.
  • Base de données cloud : Stockage des données de référence enrichies (modifications éditoriales, validations professionnelles) dans une base Supabase PostgreSQL.
  • Service de référence IA : Système de réponses informatives générées par intelligence artificielle à titre documentaire et éducatif.

Données cloud :

  • Données de profil utilisateur (nom, domaine d'activité, structure).
  • Logs de navigation à des fins de statistiques anonymisées de pertinence du contenu.
  • Contenus de référence validés et enrichis par les éditeurs.

Les données échangées avec les services cloud Supabase sont protégées par les conditions de service Supabase. L'éditeur DzPédiatrie ne stocke pas de données cliniques réelles dans son infrastructure cloud.

6. Images et Photographies

Gestion des images dans l'application :

  • Images illustratives éducatives : Les utilisateurs peuvent sélectionner des images depuis leur galerie à des fins de référence visuelle documentaire dans l'application.
  • Traitement local : Les images sélectionnées sont traitées localement sur l'appareil et ne sont pas analysées par un système de diagnostic.
  • Stockage temporaire : Les images ne sont stockées uniquement que dans la session d'utilisation en cours, à des fins de référence illustrative.

Pas d'analyse par intelligence artificielle :

  • DzPédiatrie n'utilise pas les images téléversées par intelligence artificielle ou tout autre moyen automatisé.
  • Les images sont uniquement utilisées à titre de référence illustrative dans le contexte de référence éducative.
  • Aucune image n'est transmise à des services cloud tiers pour analyse ou stockage.

Pour tout usage clinique réel impliquant des images médicales, consultez directement un professionnel de santé qualifié.

7. Fonctionnalités de Référence IA

Service de réponses informatives générées par IA :

  • Réponses documentaires : DzPédiatrie utilise un service d'intelligence artificielle pour générer des informations de référence à caractère éducatif et documentaire.
  • Contenu de référence : Les réponses générées constituent des informations pédagogiques illustratives, à comparer et vérifier selon les protocoles officiels.
  • Indicateurs de fiabilité : Chaque réponse est associée à un indicateur de fiabilité (Élevée, Moyenne, Faible) pour informer l'utilisateur du niveau de certitude documentaire.

Limitations et avertissements :

  • Les réponses générées ne constituent pas un avis médical, une consultation, ou une aide à la décision clinique.
  • Les informations doivent être vérifiées selon les protocoles officiels par un professionnel de santé qualifié avant toute utilisation.
  • DzPédiatrie ne remplace pas l'expertise d'un professionnel de santé.
  • Les réponses ne diagnostiquent pas et ne prescrivent pas.

Modes d'utilisation :

  • Référence documentaire : Accès à des informations de référence à des fins pédagogiques.
  • Recherche documentaire : Interrogation de l'IA pour retrouver des informations documentées dans la base de référence.
  • Éléments de révision : Utilisation des réponses comme supports de révision et de formation continue.

L'ensemble des informations générées par IA dans DzPédiatrie est strictement à usage éducatif et documentaire. L'utilisateur est responsable de la vérification des informations selon les protocoles officiels.

8. Infrastructure Supabase

Plateforme Supabase :

  • Authentification sécurisée : Service Supabase Auth pour la gestion des identités et sessions utilisateurs.
  • Base de données PostgreSQL : Stockage cloud des données de référence DzPédiatrie.
  • Service de références IA : Infrastructure pour les réponses informatives générées par IA.

Données stockées côté cloud :

  • Données de profil utilisateur (compte, domaine d'activité).
  • Logs de navigation à des fins statistiques anonymisées.
  • Contenus de référence enrichis et validés par les éditeurs.
  • Données de vaccination de référence (calendrier, règles).

Données NON stockées côté cloud :

  • Fiches patients fictionalisées (stockage local uniquement).
  • Images sélectionnées par l'utilisateur (traitement local uniquement).
  • Données sensibles de patients réels (DzPédiatrie n'est pas un système de gestion clinique).

Protection des données :

  • Accès protégé par authentification Supabase.
  • Politique de rétention des données conforme aux réglementations applicables.
  • Aucune donnée médicale réelle n'est stockée dans l'infrastructure cloud.

9. Vos Droits (RGPD / Réglementation Algérienne)

Conformité réglementaire :

  • Droit d'accès : Vous pouvez demander l'accès à l'ensemble de vos données personnelles stockées.
  • Droit de rectification : Vous pouvez corriger toute information inexacte vous concernant.
  • Droit à l'effacement : Vous pouvez demander la suppression de vos données personnelles.
  • Droit à la portabilité : Vous pouvez demander une copie de vos données dans un format lisible.
  • Droit d'opposition : Vous pouvez vous opposer au traitement de vos données à des fins statistiques anonymisées.

Exercice de vos droits :

  • Pour exercer vos droits, contactez l'éditeur via les canaux indiqués dans la section contact.
  • Les demandes seront traitées dans un délai raisonnable conforme à la réglementation applicable.
  • Les données localisées sur l'appareil (fiches patients fictionalisées) peuvent être supprimées directement par l'utilisateur via la désinstallation de l'application.

DzPédiatrie ne constitue pas un système de gestion clinique et ne stocke pas de données médicales réelles. Les fiches patients sont fictionalisées et à usage strictement éducatif.
